# Desktop Pet Companion

一个基于 Python 与 PySide6 的跨平台桌面宠物原型。应用提供 5 个默认的可爱动物形象，用户也可以加载自己的图片或动画作为宠物。宠物以无边框、透明的窗口呈现在桌面上，可以四处漫步、在热点区域驻足，也能通过鼠标与您互动。

## 功能概览

- **五种默认宠物**：内置星空猫、绿尾狐、夕阳兔、极光犬、云影鸮等五位伙伴。默认形象由矢量绘制生成，保证在高 DPI 屏幕上也清晰。
- **自定义宠物**：在启动对话框中可以导入 PNG、JPG、GIF 或 APNG 作为宠物外观，并为其命名。
- **桌面漫游**：宠物窗口默认贴靠屏幕底部，并随机移动；拖拽宠物即可重新定位。
- **热点互动**：双击宠物打开热点编辑器，在屏幕上绘制矩形区域，宠物会尝试靠近这些区域，实现“趴在卡片上”等效果。
- **鼠标逗宠**：点击宠物会触发跳跃动画，拖拽时会进入“玩耍”状态，移动速度减缓。

## 环境准备

1. 安装 Python 3.9 或更高版本。
2. 创建虚拟环境（推荐）：

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows 下使用 .venv\\Scripts\\activate
   ```

3. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

## 运行

```bash
python -m desktop_pet
```

运行后会先显示宠物选择窗口。确认后宠物会出现在桌面上：

- 单击：宠物原地弹跳。
- 拖拽：重新摆放位置，并降低移动速度。
- 右键：让宠物恢复普通速度。
- 双击：打开热点编辑器，使用鼠标左键绘制新热点、右键移除热点。

## GitHub Actions 自动打包

推送到 `main` 或 `master` 分支（或针对它们创建 PR）时，GitHub Actions 会在 Windows 环境下运行 PyInstaller，生成 `DesktopPet.exe`。

1. 打开仓库的 **Actions** 页面，选择最新一次 **Build Windows executable** 工作流。
2. 在运行详情底部的 **Artifacts** 区域下载 `desktop-pet-exe` 压缩包。
3. 解压后即可获得 `DesktopPet.exe`，双击运行体验桌面宠物。

## 自定义与扩展建议

- **自定义模型/动画**：目前支持导入静态或 GIF 动图。若要接入 3D 模型，可考虑集成 `Qt3D` 或使用 `panda3d`、`godot` 等引擎再通过嵌入式窗口呈现。
- **多宠物支持**：可以扩展 `MainController`，允许创建多个 `DesktopPetWindow` 实例，并为每个宠物配置独立的热点策略。
- **与前景窗口的深度交互**：当前热点是手动绘制的矩形。若要自动贴合最前端应用，可结合平台 API（如 Windows 的 `pywin32`, macOS 的 `pyobjc`）获取前台窗口矩形后，将其转换为热点。
- **行为系统**：可在 `PetController` 中增加有限状态机，定义待机、攀爬、互动等动画序列，使宠物表现更丰富。

## 开发笔记

- 代码组织在 `desktop_pet/` 包内。
- `app.py` 包含应用入口、窗口与热点逻辑。
- `pet.py` 定义宠物外观与运动控制器。
- `hotspots.py` 提供热点数据结构与全屏编辑器。
